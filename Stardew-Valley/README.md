# 🌾 Stardew Valley 攻略站

## 项目结构

```
stardew-guide/
├── index.html                     # 首页 ✅
├── README.md
├── planting/                      # 种植模块 ✅
│   ├── index.html                # 种植指南
│   ├── crops.html                # 作物大全
│   ├── tips.html                 # 种植技巧
│   ├── seasons.html              # 季节规划
│   └── fertilizer.html           # 肥料使用
├── fishing/                       # 钓鱼模块 ✅
│   ├── index.html                # 钓鱼指南
│   └── locations.html            # 钓点位置
├── mining/                        # 采矿模块 ✅
│   └── index.html                # 采矿指南
├── farming/                       # 农场模块 ✅
│   ├── index.html                # 农场指南
│   ├── layout.html               # 农场布局
│   └── upgrades.html             # 设施升级
└── items/                         # 物品模块 ✅
    └── index.html                # 物品百科
└── assets/
    └── css/
        └── style.css
```

## 功能特性

- 📱 响应式设计（支持手机/平板）
- 🎨 Stardew Valley 风格配色

- 纯 HTML/CSS (无框架，轻量快速)
